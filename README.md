## Previous Fujitsu Challenge Report

[Read the report](docs/prior-work/Q-AeroSolve_Fujitsu_2026_Report.pdf)

**Authors:** J K Pawan Kumar and Tarun Solanki
**Report date:** 27 May 2026
**Prepared for:** Fujitsu Quantum Simulator Challenge 2026

The report documents exploratory work in Taylor–Green vortex
simulation, spectral methods, low-rank compression, AI-assisted
forecasting, and distributed quantum simulation.

This is prior work. Its reported performance figures have not
been independently reproduced for the new Airbus proposal.
The proposed tensor-network finite-volume solver and gate-based
pressure-correction workflow are new Phase 2 development tasks.

This repository currently contains supporting documentation.
